# GoGo Board – Context Information for Privacy Policy Generation

**Purpose of this document**  
This document provides factual, non-legal context about the GoGo Board ecosystem.  
It is intended to help an AI system or writer generate a well-informed Privacy Policy using a separate template file.

This document describes **what the GoGo Board is**, **who uses it**, **how it is used**, and **what types of data are typically involved**.

---

## 1. What Is the GoGo Board?

The GoGo Board is an **education-focused hardware and software platform** designed for STEM learning.  
It enables students to build projects involving:

- Programming
- Sensors and data collection
- Robotics and automation
- Internet of Things (IoT)
- Data science and basic AI concepts

The platform emphasizes **learning and experimentation**, not commercial or consumer tracking.

---

## 2. Core Components of the GoGo Board Ecosystem

The ecosystem consists of three tightly connected parts:

### 2.1 Hardware (GoGo Board)

A programmable controller board used in classrooms and workshops.

Typical features:
- Digital and analog input/output
- Built-in sensors (e.g., light, sound, motion)
- Support for external sensors and actuators
- USB or wireless connection to a computer

The hardware itself does **not operate independently** on the internet; it connects through user devices or local systems.

---

### 2.2 Programming Environment (Web-Based)

A web-based programming interface that allows users to:

- Write or assemble programs (often block-based or simplified code)
- Upload programs to the GoGo Board
- Read sensor data from the board
- Log and visualize data for experiments

This environment runs in a browser and requires user authentication.

---

### 2.3 Online Learning & Classroom Platform

An online platform that supports classroom use, including:

- Teacher-created classes
- Student enrollment into classes
- Assignment distribution
- Project submission and review
- Progress monitoring

This platform is typically accessed via:
- `https://code.gogoboard.org`
- Related GoGo Board web services

---

## 3. Who Uses the GoGo Board Platform

The platform is designed primarily for **formal and semi-formal education**.

### 3.1 Students
- Usually middle school, high school, or university level
- Many users are **under 18**
- Use the platform as part of school activities

### 3.2 Teachers / Instructors
- Create and manage classes
- View student work and progress
- Provide feedback

### 3.3 School or Institutional Administrators
- Oversee usage at the school or program level
- May manage accounts or access permissions

### 3.4 Other Users (Limited)
- Workshop participants
- Teacher trainees
- Researchers (non-public access)

---

## 4. Educational Context and Philosophy

The GoGo Board is built on **constructionist learning principles**, emphasizing:

- Project-based learning
- Learning by making
- Creativity and experimentation
- Peer learning

Because of this:
- Users generate a large amount of **user-created content**
- Content reflects learning progress, not personal profiling

---

## 5. Typical Data Flow (High-Level)

1. A teacher creates a class on the platform
2. Students join using school-provided access
3. Students create programs and projects
4. Programs interact with GoGo Board hardware
5. Data may be:
   - Displayed in real time
   - Logged for later analysis
   - Submitted as part of assignments

Data remains within the **educational context** of the class.

---

## 6. Types of Data Commonly Involved

This section describes data *commonly involved*, not what must be collected.

### 6.1 User Account Data
- Name or display name
- Email (often school-provided)
- User role (student, teacher, admin)
- School or institution affiliation

### 6.2 Learning & Project Data
- Source code or block programs
- Sensor readings and logs
- Project files
- Submission timestamps
- Teacher feedback

### 6.3 Device-Related Data
- GoGo Board identifier
- Firmware version
- Connection status

### 6.4 Technical & Usage Data
- Login timestamps
- Browser and operating system
- Error or crash logs
- Basic usage analytics

The platform is **not designed for advertising or behavioral profiling**.

---

## 7. Minors and School-Based Use

Key assumptions:

- Most student users are minors
- Accounts are usually created or supervised by schools
- Consent is typically managed at the institutional level
- The platform avoids collecting:
  - Sensitive personal data
  - Location tracking
  - Financial data

---

## 8. Research and Improvement Use

Aggregated or anonymized data may be used for:

- Improving learning tools
- Educational research
- Evaluating learning outcomes

Such use is **not intended to identify individuals**.

## 9. Organizations Involved

- The GoGo Board originated from academic research
- Development and distribution are managed by an educational spin-off company
- Universities and schools act as deployment partners

Exact legal entities should be defined in the Privacy Policy using verified inputs.

## 10. Important Non-Goals of the Platform

The GoGo Board platform is **not** intended for:

- Commercial advertising
- Selling user data
- Social networking
- Personal data monetization
- Tracking users outside educational activities
